# Fermata Op. 1

Metalófono virtual educativo (PWA): modo Tradicional, Interactivo (con micrófono) y Hero (juego rítmico). Carga tus propios MIDI, graba pantalla+audio, hoja de práctica imprimible.

Esta carpeta se publica automáticamente como sitio web con GitHub Pages — es la fuente que usa el empaquetado TWA para Google Play.
